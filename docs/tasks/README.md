# Tasks

[task-list.md](task-list.md) is KiwiBot's task list until the custom task system replaces it (0016, T15). The rules for adding and updating tasks are in [0029](../decisions/0029-bootstrap-workflow.md).

- Copy [template.md](template.md) to add a task. Every task has: status, size, dependencies, decisions, goal and done-when, plus optional notes.
- Tasks are grouped by milestone (M0, M1, …), and IDs are never reused or renumbered.
