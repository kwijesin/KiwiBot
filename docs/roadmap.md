# Roadmap

KiwiBot's roadmap is mostly **decided by KiwiBot itself**: decisions become plans, and plans become tasks (0019). This page only shows the big shape. The current, detailed work lives in the [task list](tasks/task-list.md).

## Phase 1: Self-improvement loop (first build priority, 0022)
Get the loop running: intake → decision loop → plan → task → execution → daily review.
See the [task list](tasks/task-list.md), milestones **M0** (bootstrap) and **M1** (loop v0).

## Phase 2: First features built by the loop
Picked and planned through the loop itself. Likely early candidates, based on the decisions so far:
- **Custom task system** (0016), replacing the markdown task list
- **Voice-to-text input** (0018, early core feature)
- **Self-restart / supervision research** (0027, D01)
- A first **review interface** beyond markdown and pull requests (0021, D06)

## Later: candidate features (not decided)
Ideas from the early drafts. They'll be considered by the loop when they become relevant:
- PC and phone apps (0008)
- Sandbox for agent testing (D02)
- Runtime assistant: wake word, STT/TTS, tool loop, memory (D19–D26)
- Home automation integration, with physical-world safety (D25, D27)
- Mirror conversion, `MMM-Lulu` module, avatar and content display (0009, D30–D32)
- Local models and routing (D08–D10), usage metering (D11), evaluation (D12)
- Security hardening (0014, D34–D36)
