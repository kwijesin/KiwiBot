# 0011. Style framework

- **Status:** Accepted
- **Date:** 2026-11-02
- **Tags:** architecture, standards

## Decision
A **framework for consistent style** will be developed. It covers both:
- the **architecture of feature types**: how each kind of feature is structured; and
- **visual styles**: how features look across interfaces.
