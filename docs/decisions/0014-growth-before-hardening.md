# 0014. Growth first, hardening later

- **Status:** Accepted
- **Date:** 2026-11-02
- **Tags:** philosophy, security

## Decision
KiwiBot should **eventually be privacy- and security-hardened**.

In the early stages, while KiwiBot grows, security **doesn't take priority over growing its own ability to grow**.
