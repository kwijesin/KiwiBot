# 0022. First build priority: a running self-improvement loop

- **Status:** Accepted
- **Date:** 2026-11-02
- **Tags:** roadmap, process

## Decision
The **first order of business** when building starts is getting the **self-improvement pipeline** running, so that:

1. planning ends with a **task list**;
2. an **agent works on those tasks**; and
3. **each day includes a review of each task**. I wake up to a review and give feedback, there's more review later in the day, and so on.

This should also make the most of tokens across the **shifting usage window of Claude**, the system currently used for building. It's only the *current* one: the self-improvement pipeline is itself subject to 0020 (model-agnostic).
