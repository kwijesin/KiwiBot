# 0026. Decision intake from any input

- **Status:** Accepted
- **Date:** 2026-11-02
- **Tags:** features, process

## Decision
Decisions can enter the self-improvement pipeline through **any of KiwiBot's input methods**, for example:
- the **phone app**;
- the **PC app**;
- **voice input**;
- **KiwiBot itself**, through its own tasks (e.g. a task "make some decisions about xyz"); or
- **me using Claude pointed at the root of the system**.

The details of intake will be researched further **once the self-improvement loop is finished**.
