# 0016. Task lists as a core system

- **Status:** Accepted
- **Date:** 2026-11-02
- **Tags:** features, architecture
- **Revised:** 2026-11-02 (round 1 cascade)

## Decision
KiwiBot will likely need several task lists: one for **my own tasks**, one for **KiwiBot's tasks**, and so on.

A **task program** will probably be a core system KiwiBot uses to organize itself.

The task system will almost certainly be **fully custom** (see 0023).
