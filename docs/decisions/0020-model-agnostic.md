# 0020. Model-agnostic LLM systems

- **Status:** Accepted
- **Date:** 2026-11-02
- **Tags:** architecture

## Decision
Most, if not all, of KiwiBot's LLM-based systems should be **model-agnostic**. Models are connected to them **through configuration**.
