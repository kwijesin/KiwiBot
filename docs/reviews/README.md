# Reviews

One review note per task, kept in git so the review history isn't lost ([0029](../decisions/0029-bootstrap-workflow.md)). The format is set by [0031](../decisions/0031-review-format.md).

- Copy [template.md](template.md) to:
  - `Txx-short-name.md` for a task (e.g. `T05-feature-types-and-conventions.md`), or
  - `Mx-short-name.md` for a milestone review (e.g. `M0-bootstrap.md`).
- The **review queue** is every `⏸ Awaiting review` task in the [task list](../tasks/task-list.md).
